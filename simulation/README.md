# Simulation assets

This directory contains the Gazebo worlds, models, integration adapters, and
owned-process experiment harnesses.

- `worlds/` — full mission and sensor-test worlds.
- `models/` — aircraft, environment, banner, QR, and sensor models.
- `integration/` — non-ROS mission manager, camera/LiDAR adapters, benchmarks,
  and validation harnesses.
- `experiments/` — isolated corridor and LiDAR experiments.
- `scripts/` — camera viewers and launch helpers.

Run commands from the repository root and use the `src/` paths documented in
the root README and the integration handoff.
